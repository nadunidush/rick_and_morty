# Rick_and_Morty

Developed modern and responsiveness web adn mobile application browsing content from animated series of Rick_and_Morty.

## 🧑‍💻 Tech Stack Used

* Framework: Flutter
* Language: Dart
* API Integration:
     * **Rick and Morty API:** For fetching characters and episodes data.
* State Management: 
     * **ValueNotifier:** for store the memory of watchlist all episodes.
     * **setState:** For managing the local widgets states on the application.
* UI/UX: Use **MediaQuery** for responsive for Desktop, Tablet, and Mobile.

## ↗️ Steps to run the project
1. **Install the Flutter SDK:**
   * If you don't have flutter in local machine please install the flutter sdk using offial website of flutter.(https://flutter.dev/docs/get-started/install)

2. **Clone the project:**
   * Open the terminal
   * Navigate to the where should project keep.
   * use git clone command followed by the below repository.
       * **git clone https://github.com/nadunidush/rick_and_morty**
   * Navigate to the project
       * **cd rick_and_morty**
   * Get dependencies
       * **flutter pub get**
   * Run the application
       * **flutter run or flutter run -d windows # or macos, linux**
